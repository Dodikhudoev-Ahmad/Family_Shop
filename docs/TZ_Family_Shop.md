# Техническое задание
## Интернет-магазин «Family Shop»

---

## 1. Общее описание

**Название проекта:** Family Shop
**Тип:** интернет-магазин одежды (мужская, женская, детская)
**Референс дизайна:** milanomoda.store (структура карточек, хедер, минимализм)
**Приоритет отображения:** mobile-first

---

## 2. Технологический стек

| Слой | Технология |
|---|---|
| Frontend | React + TypeScript + Vite |
| Backend | ASP.NET Core Web API |
| ORM | Entity Framework Core |
| БД | PostgreSQL |
| Аутентификация | JWT + refresh tokens |
| Деплой frontend | Vercel |
| Деплой backend + БД | Render / Railway |

---

## 3. Дизайн-система

### 3.1 Цветовая палитра
- **Фон основной:** `#FFFFFF`
- **Фон карточек/секций:** `#F7F5F3` (тёплый off-white)
- **Текст основной:** `#1A1A1A` (графит, не чистый чёрный)
- **Текст вторичный:** `#8A8A8A` (категории, старая цена)
- **Акцент:** `#C17A54` (терракота — скидки, кнопки, hover)

### 3.2 Принципы
- Компактные карточки товара, без огромных фото на весь экран
- Много воздуха, но не в ущерб плотности каталога
- Крупная, но не декоративная типографика
- Единый визуальный язык для мужской/женской/детской категорий

### 3.3 Сетка каталога
- **Мобиль (375–430px):** 1 карточка в ряд
- **Десктоп:** 4 карточки в ряд

## 4. Структура сайта

### 4.1 Хедер
- Логотип
- Категории: Женское / Мужское / Детское / Обувь и сумки
- Поиск
- Иконка входа
- Корзина (счётчик товаров)

### 4.2 Главная страница
- Hero-блок: 2–3 плитки по категориям (Женское / Мужское / Детское)
- Секция «Новинки недели»
- Секция «Хиты продаж» (по категориям)

### 4.3 Карточка товара (превью)
- Фото товара
- Бейдж скидки (напр. −20%)
- Категория (мелким серым текстом)
- Название товара
- Цена (старая зачёркнутая + новая)
- Иконки: избранное, быстрый просмотр

### 4.4 Страница товара
- Галерея фото
- Название, цена, описание
- Выбор размера/цвета
- Кнопка «В корзину»

### 4.5 Каталог/категория
- Фильтры (категория, размер, цена, скидка)
- Сетка карточек с пагинацией

### 4.6 Корзина и оформление заказа
- Список товаров, изменение количества
- Форма доставки и оплаты
- Подтверждение заказа

### 4.7 Личный кабинет
- Регистрация/вход
- История заказов
- Избранное

## 5. Схема базы данных (основные таблицы)

- **Products**: id, name, description, price, discountPrice, stock, categoryId, gender (male/female/kids), images
- **Categories**: id, name, parentCategoryId
- **Orders**: id, userId, status, totalPrice, createdAt
- **OrderItems**: id, orderId, productId, quantity, price
- **Users**: id, email, passwordHash, name, role

---

## 6. Backend: API endpoints (минимум)

- `GET /api/products` — список товаров (фильтр по gender/category/price)
- `GET /api/products/{id}` — карточка товара
- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/orders` — создание заказа
- `GET /api/orders` — история заказов пользователя

---

## 7. Требования к безопасности

- Хэширование паролей (bcrypt/Argon2)
- JWT + refresh tokens, срок жизни access-токена короткий
- Rate limiting на auth-эндпоинтах
- Валидация всех входных данных (backend, не только frontend)
- Параметризованные запросы через EF Core (защита от SQL-инъекций)
- Строгая настройка CORS
- HTTPS everywhere
- Оплата — только через сертифицированный платёжный шлюз (Stripe/аналог), номера карт не хранятся на сервере

## 8. Этапы разработки

1. Инициализация репозиториев (frontend/backend)
2. Настройка проектов (Vite+React+TS, ASP.NET Core+EF Core)
3. Дизайн-токены (цвета, типографика, отступы)
4. Схема БД + миграции
5. Backend: базовые endpoints + аутентификация
6. Frontend: карточка товара
7. Frontend: сетка каталога + хедер
8. Интеграция frontend↔backend
9. Корзина, оформление заказа, оплата
10. Личный кабинет
11. Тестирование (mobile-first, реальные устройства)
12. Деплой (Vercel + Render/Railway)

# Роли и права

Источник фактов: `backend/Domain/Entities/User.cs` (`UserRole`), контроллеры `backend/Api/Controllers/`, `backend/Api/Program.cs`, `CLAUDE.md` (3.4).

## Роли

| Роль | Как определяется | Токен |
|---|---|---|
| Гость | нет access-токена | — |
| Покупатель (`Customer`) | вошёл, `UserRole.Customer` | JWT, claim роли `Customer` |
| Администратор (`Admin`) | вошёл, `UserRole.Admin` | JWT, claim роли `Admin` |

Админ создаётся сидером при старте (пароль из `Seed__AdminPassword`, вне Development без него админ не создаётся). Через регистрацию админом стать нельзя.

## Что разрешено

| Действие | Гость | Покупатель | Админ |
|---|---|---|---|
| Каталог, товар, категории, активные баннеры, отзывы (чтение), проверка промокода | да | да | да |
| Регистрация, вход, refresh, logout | да | да | да |
| Создать заказ, история своих заказов | нет | да | да (технически) |
| Оставить / удалить свой отзыв, получить «мой отзыв» | нет | да | да |
| Свои сессии, выход со всех устройств, отзыв своей сессии | нет | да | да |
| Удалить свой аккаунт (`DELETE /auth/me`) | нет | да | нет, 403 (удаляется вручную) |
| `/admin/*`: товары, категории, баннеры, промокоды, заказы, статистика, отзыв сессий пользователя | нет (401) | нет (403) | да |

## Как это обеспечено в коде

1. **FallbackPolicy** (`Program.cs`, строка ~116): `RequireAuthenticatedUser` для всех эндпоинтов без атрибутов. Новый эндпоинт без атрибута закрыт для гостей.
2. **Публичные действия** помечены `[AllowAnonymous]` на **действии**, не на контроллере (на классе он перебил бы `[Authorize]` у действий).
3. **Админские контроллеры**: `[Authorize(Roles = "Admin")]` на классе (`AdminProducts/Categories/Orders/PromoBanners/PromoCodes/Users`).
4. **Тест на рефлексии** `EndpointAuthorizationTests` фиксирует список анонимных действий и роль у всех `/admin/*`. Новый публичный эндпоинт придётся добавить в тест осознанно.
5. **Идентификатор пользователя** берётся только из токена (claim `NameIdentifier`), не из тела или query.
6. **Удалённый аккаунт**: `ActiveAccountTokenValidator` отклоняет его access-токен на каждом запросе.
7. **Отзыв сессий**: access-токен живёт 15 минут и переживает отзыв сессии (открытая задача, `TODO.md`, п. 2).

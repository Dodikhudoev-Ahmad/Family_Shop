## 6. Риски и ограничения

1. **Удаление необратимо из интерфейса:** вернуть удалённый расход нельзя (только внести заново). Строка остаётся в БД; восстановить можно вручную SQL (`IsDeleted = false`).
2. **Имя поля `ordersToday`** теперь значит «доставлено сегодня» (поле не переименовывал, чтобы не ломать клиентов). Старый сервер не отдаёт `newToday` — сайт показывает 0.
3. **Нет верхней границы** у «Новых сегодня» и платежей «сегодня» (`DRIFT.md`, B19): безвредно, будущих записей нет.
4. **Окно деплоя:** старый API между миграцией и выкладкой кода не знает про `IsDeleted` (колонка по умолчанию false, расходы видны и считаются как раньше) — риска потери данных нет.
5. Сторно `Delivered → Cancelled` по-прежнему не включено (`docs/StateMachines.md`).
6. `Down()` миграции содержит `DROP COLUMN` (только для локального отката; откат схемы на проде — из бэкапа).
7. Mobile не менялся.

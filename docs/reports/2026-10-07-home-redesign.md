# Отчёт: Фаза 14, шаг 8 — редизайн главной, цветная шапка [FE]

Дата: 2026-10-07. Только frontend; backend, mobile и прод не менялись, пуша не было.

## 1. Итог

Шапка стала цветной (терракотовый градиент, в варианте B — графит и бордо), главная получила баннер акции, чипы быстрых фильтров, бейджи, полосы секций и новую нижнюю панель. Два варианта переключаются `?variant=a|b` (по умолчанию `a`), на телефоне 2 карточки в ряд из одного токена.

## 2. Причина

Главная была одноцветной (белый фон и один акцент). Решение владельца — «как у маркетплейса», но на собственных цветах. Правила — [docs/Design.md](../Design.md) (написан первым).

## 4. Решения, принятые самостоятельно

- Контраст: чистая терракота `#C17A54` с белым текстом даёт 3,4:1, поэтому начало градиента A — `#965230` (белый 5,9:1, приглушённый текст 4,98:1, акцент логотипа 4,84:1). Это цвет, не текст, затемнён по заданию.
- Табы: «Все» + все категории магазина (не только три), порядок как в API. «Все» ведёт в `/catalog`. На десктопе полосы табов нет — там прежнее меню «Каталог».
- Чипы фильтруют подборку на месте (без запросов); «Новинка» — по `createdAt` ≤ 30 дней (`NEW_PRODUCT_DAYS`), поля `isNew` API не отдаёт. Блок «Новинки недели» стал подборкой с чипами.
- Баннер акции не рисуется, если нет ни одного товара со скидкой; «до −N%» — реальный максимум.
- Расхождение: ТЗ и прежний CLAUDE.md говорили «1 в ряд на телефоне», в коде уже было 2. Записано в `docs/DRIFT.md` (A18), CLAUDE.md обновлён.
- Избранное «локально в localStorage» уже было (`FavoritesContext`); добавлены тесты, логику не менял.

## 6. Риски

- Не проверено: реальный iPhone и Safari (`backdrop-filter`, safe-area); `prefers-reduced-motion` проверен только в Chromium с включённой эмуляцией.
- Белый цвет на терракоте теперь не используется в бейдже скидки и счётчике: они стали темнее по тексту — заметно по виду, проверьте на глаз.
- «Избранное» исчезло из нижней панели: дойти можно через бургер-меню и десктопную шапку; если нужно в панели, это пятый таб (на 320 px тесно).
- Вариант хранится в `sessionStorage`: ссылка без параметра в той же вкладке сохранит B.
- `Hero`-плитки и поисковый оверлей цветов не меняли; в `Hero` остались прежние rgba-затемнения фото.

Закрой текущий шаг. Аргументы (номер фазы, шага, тег): $ARGUMENTS

1. Проверки (по очереди, из корня репозитория):
   - `cd backend && dotnet build FamilyShop.slnx` — должно быть 0 ошибок и **0 предупреждений**;
   - `cd frontend && npx tsc -b` и `npm run test`;
   - `cd mobile && npx tsc --noEmit` и `npx jest`;
   - `cd backend && dotnet test FamilyShop.slnx --no-build`.
2. Если что-то красное или есть предупреждения: **остановись**, доложи (какая команда, что вывела) и **не коммить**. Шаг не закрыт.
3. Если всё зелёное:
   - отметь шаг в `PROGRESS.md` (`[x]`);
   - обнови блок «Current Status» в `claude.md` (фаза, последний коммит, следующий шаг, числа тестов, дата);
   - сделай коммит в формате «Phase X Step Y [BE|FE|FULL]: описание» (в конце — строка Co-Authored-By из системной инструкции);
   - не пушь;
   - вызови `/report`;
   - назови следующий шаг из `PROGRESS.md` и жди моего «go».

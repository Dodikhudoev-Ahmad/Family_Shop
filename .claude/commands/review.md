Проверь изменения (`git diff` и `git diff --staged`; если пусто — `git diff HEAD~1`). Код не правь, только перечисли нарушения.

Проверь по пунктам:

1. **Миграции**: только аддитивные и идемпотентные (`IF NOT EXISTS`), нет DROP/удаления/пересоздания; сверь с `docs/Database.md`.
2. **Секреты**: нет паролей, ключей, строк подключения, токенов (в том числе в тестах, `appsettings*.json`, `.env`).
3. **Роли и доступ**: новые эндпоинты закрыты по умолчанию, `[AllowAnonymous]` на действии, `/admin/*` под `Admin`, список в `EndpointAuthorizationTests` обновлён; сверь с `docs/Roles.md` и `docs/Api.md`.
4. **Деньги**: `Money`/decimal, округление, статусы в подсчётах; сверь с `docs/Money.md`.
5. **Часовой пояс**: границы периодов из `StoreClock`, не `DateTime.UtcNow.Date`.
6. **Склад и заказы**: атомарность, статусы — `docs/StateMachines.md`.
7. **Тесты**: у каждого изменения поведения есть тест (успех, 401/403, ошибка); нет удалённых или отключённых тестов.
8. **Смешение слоёв**: BE, FE и mobile в одном шаге только с тегом [FULL].
9. **Docs**: изменение поведения отражено в `docs/` и `CLAUDE.md`.

Вывод: список нарушений по важности (Критично / Важно / Мелочь), у каждого файл:строка и что сделать. Если нарушений нет — так и скажи.

Подготовь миграцию: $ARGUMENTS. Тег [BE]. Прод не трогать.

Порядок:

1. **Только аддитивная**: добавление таблицы/столбца/индекса, UPDATE данных. Никакого DROP, удаления и пересоздания таблиц, а для Order/Review и записей с FK на них — ни удаления, ни пересоздания.
2. **Идемпотентная**: в SQL миграции `IF NOT EXISTS` / `ADD COLUMN IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS`. Образец: `AddProductAvailableSizes`, `AddIdempotencyKeys`.
3. Изменение каталога/категорий — только идемпотентным UPDATE по ключу.
4. Применить на локальной БД (порт 5433), проверить повторный запуск, проверить, что старые данные целы. Если нужна временная БД — `familyshop_test_*`.

6. **Откат**: опиши в отчёте, как вернуться (откат кода безопасен, схема остаётся; откат схемы только из бэкапа).
